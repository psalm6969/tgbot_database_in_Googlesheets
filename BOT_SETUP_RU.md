# Настройка Telegram-бота для сбора email

Бот принимает email-сообщения в Telegram, проверяет формат и добавляет каждый адрес в Google Sheets на лист **«Задача 3»**.

В таблицу записываются четыре поля: время получения, email, Telegram username или ID отправителя, ID сообщения для обработки.

## 1. Замени токен бота

Токен, отправленный в переписку, нужно отозвать: открой **@BotFather**, отправь `/revoke` и выбери бота. Затем создай новый токен.

Новый токен не отправляй в чат и не сохраняй в файлах проекта. Передавай его программе через локальную переменную окружения, как показано ниже.

## 2. Подготовь Google-таблицу

1. Загрузи [Excel-файл](AI_content_department_and_competitors.xlsx) в Google Drive и открой его как Google Таблицу.
2. Убедись, что в таблице есть лист с названием **Задача 3**.
3. Скопируй ID таблицы из адреса вида `https://docs.google.com/spreadsheets/d/ID_ТАБЛИЦЫ/edit`.
4. В Google Cloud Console создай проект и Service Account.
5. Включи **Google Sheets API** для проекта и создай JSON-ключ сервисного аккаунта.
6. Скачай JSON-ключ в папку проекта под именем `google-service-account.json`.
7. Открой JSON-ключ локально, найди поле `client_email` и предоставь этому адресу доступ **Редактор** к таблице.

На листе **Задача 3** желательно задать заголовки столбцов:

| A | B | C | D |
|---|---|---|---|
| Время получения | Email | Telegram user | Update ID |

## 3. Установи зависимость

В PowerShell, находясь в папке проекта, выполни:

```powershell
.\.venv\Scripts\python.exe -m pip install -r .\requirements-email-bot.txt
```

## 4. Запусти бота

Вставь новый токен локально в PowerShell. Не отправляй его в чат и не делай скриншот этой команды.

```powershell
$env:TELEGRAM_BOT_TOKEN = 'ВСТАВЬ_НОВЫЙ_ТОКЕН'
$env:GOOGLE_SPREADSHEET_ID = 'ID_ТАБЛИЦЫ'
$env:GOOGLE_SERVICE_ACCOUNT_FILE = '.\google-service-account.json'
.\.venv\Scripts\python.exe .\email_capture_bot.py
```

Оставь окно PowerShell и процесс запущенными. На сервере программу можно держать включённой постоянно.

Открой бота в Telegram, нажми **Start** и отправь email, например `name@example.com`. После записи бот подтвердит её, а новая строка появится на листе **Задача 3**.

## Доступ для пользователей

Бот принимает сообщения от **всех пользователей Telegram**. Любой, кто найдёт бота и нажмёт **Start**, сможет отправить адрес; корректные email будут записаны в таблицу вместе с username или ID отправителя.

## Если запись не появляется

- Проверь, что в переменной `GOOGLE_SPREADSHEET_ID` указан ID нужной таблицы.
- Проверь точное имя вкладки: `Задача 3`.
- Убедись, что `client_email` сервисного аккаунта имеет в таблице права **Редактор**.
- Проверь, что Google Sheets API включён и JSON-ключ лежит по указанному пути.
- Если токен отозван или недействителен, выпусти новый через **@BotFather** и задай переменную `TELEGRAM_BOT_TOKEN` заново.

## Безопасность

- Не добавляй токен, `google-service-account.json` и `email_bot_state.json` в Git или общие чаты.
- Бот собирает email и Telegram username/ID. Перед использованием адресов для рассылки настрой необходимое уведомление и согласие на обработку данных.
- Бот работает через long polling: отдельный webhook не нужен, но компьютер или сервер со скриптом должен быть включён.
